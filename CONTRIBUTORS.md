# Contributors

Vantra Automation Hub recognizes every person whose meaningful pull request is merged.

## How recognition works

After a contributor's first merged pull request, add one row containing their GitHub username, the contribution type, and the merged pull request number. The contributor may include this update in the same pull request or a maintainer may add it during review.

## What counts as a contribution

A contribution must improve the project in a useful, reviewable way. Examples include a working workflow, validator test, accurate translation, setup guide, security improvement, bug fix, or accessible website improvement.

Meaningless one-line edits, duplicate changes, generated spam, credential leaks, or coordinated fake pull requests will not be merged.

## Credit and ownership

Contributors keep copyright in their work and submit it under the repository's MIT License. Recognition does not create employment, payment, sponsorship, or eligibility for third-party benefits.
