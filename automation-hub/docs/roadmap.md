# Roadmap

## Milestone 1 — Contributor-ready foundation

- Publish the repository and use a clear project name.
- Maintain at least five validated example recipes.
- Provide contributor, security, conduct, Issue, and pull request guidance.
- Add automated validation for every recipe pull request.
- Prepare small independent Issues for first-time contributors.

## Milestone 2 — Useful recipe catalog

- Cover at least ten business categories.
- Add recipe indexes by platform, business type, and difficulty.
- Add implementation examples for n8n and Make using synthetic data.
- Add English, Spanish, and Portuguese documentation.
- Add accessibility and privacy review checklists.

## Milestone 3 — Community maintenance

- Establish predictable review standards and response times.
- Add volunteer reviewers after consistent contributions.
- Publish monthly release notes and contributor acknowledgements.
- Track recipe quality, successful tests, and deprecated platform behavior.

## Non-goals

- Collecting meaningless contributions to inflate contributor counts.
- Hosting real access tokens, customer data, or proprietary client workflows.
- Claiming official affiliation with Instagram, WhatsApp, Telegram, n8n, Make, Anthropic, or other platforms.
